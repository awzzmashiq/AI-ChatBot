## 🚀 Quick Deployment Steps

### 1. Environment Setup
```bash
# Copy environment template
cp env.production.template .env

# Edit with your actual values
# Required: THETA_API_KEY, SECRET_KEY
```

### 2. Build & Deploy
```bash
# Option A: Using deployment script (Windows)
deploy-theta.bat

# Option B: Using Docker Compose
docker-compose up --build

# Option C: Manual Docker commands
docker build -t study-buddy-ai:latest .
docker run -p 5000:5000 --env-file .env study-buddy-ai:latest
```

### 3. Theta Edge Cloud Deployment
```bash
# Push to your registry
docker tag study-buddy-ai:latest your-registry.com/study-buddy-ai:latest
docker push your-registry.com/study-buddy-ai:latest

# Deploy using generated manifest
kubectl apply -f theta-deployment.yaml
```
